# 保障房与商品房长期居住成本计算器

一个可自由调整参数的静态网页计算器，用于比较保障性住房与商品房在不同居住年限下的累计净成本、退出后的净资产和现金流压力。

项目以杭州配售型保障性住房的回购计算方式为案例，支持 10 年、20 年、30 年及自定义年限比较。它是情景分析工具，所有价格、收入、CPI 和收益率参数都可以修改。

## 项目背景与出发点

在担心未来房价下跌、又有长期自住需求的情况下，购房者可能面临两个位置相近、价格和退出机制不同的选择：

- **保障房**：购入价格相对较低，可能需要自行装修；实行封闭管理，退出时按适用规则由指定机构回购。
- **商品房**：购入价格较高，可能已有装修；未来可以按适用规定出售，退出价格受具体房屋和市场变化影响。

最初的问题是：假设两个小区面对面、只隔一条马路，保障房约 120 万元、商品房约 250 万元，两者都贷款 30 年，居住 10、20 或 30 年后退出，哪种方案的财务结果更合适？

单看房价、首付、月供或退出时拿回的钱，都不足以回答这个问题。因此本项目将购房、还贷、持有、退出和家庭日常收支放入同一个模型，比较相同初始资金、收入和生活开支下的结果。

本项目不对未来房价作确定性预测。下跌、持平或上涨都是用户设定的情景。

## 功能

- 调整两种住房的价格、首付比例、贷款利率、装修家电费用、购入杂费和年持有费用。
- 两种住房可分别选择等额本息或等额本金，支持不同还款方式的交叉比较。
- 调整共同的贷款期限和居住年限。
- 调整保障房折旧率、CPI 年均涨幅及商品房价格年均变化率。
- 调整初始可用存款、税后年收入、年生活开支和资金年收益率。
- 实时展示累计净成本、退出后的净资产、最低现金余额及月供收入比。
- 绘制不同退出年限下的成本曲线，并提供 10／20／30 年对照表。
- 估算使两种方案累计净成本相同的商品房售价及年均价格变化率。
- 支持恢复默认参数和商品房价格情景快捷切换。

## 数学模型

以下用下标 `a` 表示保障房，`c` 表示商品房，`j` 表示任一方案。

### 1. 贷款与两种还款方式

设购房价为 $`P_j`$，首付比例为 $`d_j`$，贷款年利率为 $`r_j`$，贷款期限为 $`T`$ 年，居住年限为 $`N`$ 年。两种住房可以分别选择还款方式。

贷款本金、月利率、贷款期数和实际已还期数分别为：

```math
L_j=P_j(1-d_j),\qquad i_j=\frac{r_j}{12},\qquad n=12T,\qquad k=\min(12N,n)
```

**等额本息**：在固定利率下，每月还款总额相同，本金占比逐步增加，利息占比逐步减少。

```math
A_j=\frac{L_j i_j}{1-(1+i_j)^{-n}}
```

已还 $`k`$ 期后的剩余本金为：

```math
B_j(N)=L_j(1+i_j)^k-A_j\frac{(1+i_j)^k-1}{i_j}
```

**等额本金**：每月归还相同本金 $`L_j/n`$，利息按月初剩余本金计算。第 $`m`$ 期还款额为：

```math
A_{j,m}=\frac{L_j}{n}+\left[L_j-(m-1)\frac{L_j}{n}\right]i_j,\qquad 1\le m\le n
```

剩余本金、首月月供、每月递减额分别为：

```math
B_j(N)=L_j\left(1-\frac{k}{n}\right),\qquad
A_{j,1}=\frac{L_j}{n}+L_ji_j,\qquad
A_{j,m}-A_{j,m+1}=\frac{L_j}{n}i_j
```

两种方式均采用各期实际还款额求和：

```math
Q_j(N)=\sum_{m=1}^{k}A_{j,m},\qquad
I_j(N)=Q_j(N)-[L_j-B_j(N)]
```

等额本息中 $`A_{j,m}=A_j`$；等额本金中各期金额递减。等额本金已付利息也可用下式交叉核对：

```math
I_j(N)=i_j\left[kL_j-\frac{L_j}{n}\frac{k(k-1)}{2}\right]
```

当利率为零时，两种方式均为每月归还 $`L_j/n`$。贷款到期后，剩余本金和后续月供均为零。

在贷款本金、期限和正利率相同的条件下，等额本金通常前期月供更高、本金下降更快、累计贷款利息更少；但前期还款占用更多现金，最终净资产还受到资金收益率、持有年限和家庭现金流的影响。不能只凭总利息判断哪种方式一定更优。

页面的“首月月供”“贷款末期月供”“月供每月递减”均使用所选还款方式计算。“贷款末期月供”指原贷款计划最后一期，不是退出年份最后一个月；“首月月供 / 月收入”用于展示起始还款压力。

### 2. 保障房回购价

设年线性折旧率为 $`\delta`$，CPI 年均涨幅为 $`c`$。模型将累计 CPI 涨幅近似为：

```math
\Gamma_N=(1+c)^N-1
```

回购价为：

```math
R_a(N)=P_a\left[1-N\delta+\Gamma_N\right]
```

**折旧按原购房价线性计算，CPI 按年度指数连乘计算。** 二者的累计方式不同。装修家电费用不加入回购价格。

该模型参考杭州公布的保障房回购公式。实际政策的折旧起止日期与 CPI 计入年度并不完全等同于居住年限；计算器为便于比较，假设购买、交付、入住同年，并使用 $`N`$ 个年度的 CPI。正式结算应以适用合同、官方指数及回购机构核定为准。

如果每年的 CPI 不同，实际累计涨幅应由各年度指数连乘得到：

```math
\Gamma_N=\prod_{t=1}^{N}(1+c_t)-1
```

当前界面使用一个固定年均涨幅，尚未提供逐年指数录入。

### 3. 商品房退出价格

设商品房价格年均变化率为 $`g`$，出售费用占售价比例为 $`\tau`$：

```math
R_c(N)=P_c(1+g)^N,\qquad F_c(N)=\tau R_c(N)
```

负的 $`g`$ 表示下跌，零表示名义价格不变，正值表示上涨。

这里的价格变化代表**这套具体房屋未来的实际转售价**。房龄、装修老化和小区变化等对售价的影响，应包含在所设情景中，模型不再额外扣一次房龄折旧。

### 4. 累计居住净成本

设装修家电费用为 $`D_j`$，购入杂费为 $`K_j`$，每年持有费用为 $`H_j`$。初始现金需求为：

```math
U_j=P_jd_j+D_j+K_j
```

保障房累计净成本：

```math
C_a(N)=U_a+Q_a(N)+NH_a+B_a(N)-R_a(N)
```

商品房累计净成本：

```math
C_c(N)=U_c+Q_c(N)+NH_c+B_c(N)-R_c(N)+F_c(N)
```

也可以写成更直观的形式：

```math
C_j(N)=P_j+D_j+K_j+I_j(N)+NH_j-R_j(N)+F_j(N)
```

其中保障房退出费用 $`F_a`$ 在当前模型中取零。

这两种写法等价。第二种写法已将首付、月供中的本金和退出时剩余本金合并为购房价，不能再重复加入本金。

页面的成本差定义为：

```math
\Delta C=C_c-C_a
```

- 正值：保障房累计净成本更低。
- 负值：商品房累计净成本更低。
- 零：两种方案累计净成本相同。

“折合每月”是累计净成本除以居住月数，用来辅助理解，**不等于月供，也不是逐月实际支出**。

累计净成本是不同年份的名义现金金额直接相加，未进行折现。若退出收入超过模型中的累计支出，净成本可能为负，表示该情景下的名义财务盈余。

### 5. 家庭现金余额与最终净资产

比较两种方案时，共同使用初始可用存款 $`S_0`$、税后年收入 $`Y`$、年生活开支 $`E`$、资金年收益率 $`s`$。

资金收益按有效年收益率换算为月收益率：

```math
q=(1+s)^{1/12}-1
```

购房完成后的现金余额：

```math
W_{j,0}=S_0-U_j
```

月末现金余额逐月递推：

```math
W_{j,m}=W_{j,m-1}+\max(W_{j,m-1},0)q
+\frac{Y-E-H_j}{12}-A_{j,m}
```

其中 $`A_{j,m}`$ 为该月应还月供，贷款到期后取零。收入、生活开支和持有费用均按月均摊；收益先按月初正现金余额计算，月末再计入当月收支。

退出并清偿贷款后的净资产：

```math
V_a=W_{a,12N}+R_a(N)-B_a(N)
```

```math
V_c=W_{c,12N}+R_c(N)-F_c(N)-B_c(N)
```

页面的“保障房净资产多出”定义为：

```math
\Delta V=V_a-V_c
```

正值表示保障房方案最终净资产更多，负值表示商品房方案更多。工资收入已经进入现金余额，不应再次加入净资产。

模型记录购房完成时及各月末的最低现金余额。若任一时点现金为负，页面会显示“现金不足”；双方均无持有期资金缺口时，才直接展示两者最终净资产差。模型不为资金缺口自动安排额外借款或融资。

最低现金余额检查的是购房后至退出前的月度资金路径，不能替代退出时清偿贷款的专项资金检查。如果房屋净退出收入不足以偿债，还需确认已有现金能否补足差额。

### 6. 支出差额的资金收益

页面还会将初始现金需求差和每月支出差按设定收益率积累至退出时，计算两方案的资金占用差异：

```math
\Delta V_{\mathrm{diff}}=(U_c-U_a)(1+q)^{12N}
+\sum_{m=1}^{12N}\left(A_{c,m}-A_{a,m}+\frac{H_c-H_a}{12}\right)\cdot(1+q)^{12N-m}
+[R_a-B_a]-[R_c-F_c-B_c]
```

其中下标 $`\mathrm{diff}`$ 表示按收支差额计算。$`R_j`$、$`B_j`$、$`F_j`$ 均取退出时的值。

当两种方案全程现金充足、收入和生活开支相同，并采用相同资金收益率时，该结果与最终净资产差一致。若出现现金缺口，这个差额计算仅是理论比较，不能视为可执行的家庭资产结果。

### 7. 商品房盈亏平衡售价

令 $`C_c(N)=C_a(N)`$，解得商品房的平衡售价：

```math
R_c^{\ast}(N)=\frac{P_c+D_c+K_c+I_c(N)+NH_c-C_a(N)}{1-\tau}
```

对应的平衡年均价格变化率：

```math
g^{\ast}=\left(\frac{R_c^{\ast}(N)}{P_c}\right)^{1/N}-1
```

这是**累计净成本的平衡点**，不是计入资金收益后的净资产平衡点。分母为零或计算无法得到有效正售价时，页面不提供有效平衡结果。

## 结果应该怎么看

建议结合三个指标：

| 指标 | 回答的问题 | 主要限制 |
|---|---|---|
| 退出后净资产 | 相同起点和家庭收支下，最后剩多少资产？ | 依赖收入、费用、退出价格及收益假设 |
| 累计居住净成本 | 这段居住经历净花了多少钱？ | 未折现，未计资金收益 |
| 月供收入比、最低现金余额 | 持有过程中是否负担得起？ | 按月均摊，未反映日内和突发资金需求 |

不同年限的成本曲线表示“在该年退出”的独立情景。10 年结果不代表先卖房、再继续住到 20 年的连续决策。

## 默认情景示例

按两种住房均采用等额本息、默认 CPI 年均上涨 1%、商品房每年下跌 1%，单位为万元：

| 居住年限 | 保障房累计净成本 | 商品房累计净成本 | 保障房少花 |
|---|---:|---:|---:|
| 10 年 | 53.43 | 73.71 | 20.28 |
| 20 年 | 78.39 | 126.21 | 47.82 |
| 30 年 | 92.62 | 157.32 | 64.70 |

再采用默认初始存款 60 万、税后年收入 20 万、年生活开支 8 万及资金年收益率 2%，住满 20 年后：

- 保障房方案最终净资产约 **262.78 万元**。
- 商品房方案最终净资产约 **187.51 万元**。
- 两者差额约 **75.26 万元**。

保持其他默认参数不变，两种住房都改为等额本金：

| 居住年限 | 保障房累计净成本 | 商品房累计净成本 | 保障房少花 |
|---|---:|---:|---:|
| 10 年 | 52.28 | 71.31 | 19.03 |
| 20 年 | 74.93 | 119.00 | 44.07 |
| 30 年 | 87.80 | 147.29 | 59.49 |

初始月供由等额本息的约 3,843／8,007 元，变为等额本金的约 4,747／9,889 元（保障房／商品房）。这体现了较少利息与较高前期现金支出的取舍。

这些结果是模型在给定参数下的输出，不是对未来资产的保证。

## 主要假设与适用边界

1. **居住价值近似相同。** 位置相近不等于房屋完全相同；面积、户型、学区、品质、物业、流动性与居住偏好没有货币化。
2. **贷款能够获批。** 用户应自行确认资格、首付要求、贷款上限和公积金余额要求。模型假定两种方案都能按输入本金贷款。
3. **支持等额本息和等额本金、固定利率。** 按所选方式逐月还款，不模拟利率调整、提前还款、组合贷款或公积金账户抵扣。
4. **购买、交付、入住同年，年末退出。** 未计等待交付期间的租金、时间差或回购等待期。
5. **保障房可以按所设机制退出。** 不自动判断回购资格、政策适用范围及合同限制，也不保证指定年限可立即完成回购。
6. **商品房能以设定价格出售。** 不模拟挂牌周期、议价、成交失败和出售期间的额外持有成本。
7. **年均变量固定。** CPI、商品房价格变化、资金收益、收入和生活费用在整个持有期内按输入值计算；未模拟收入增长或失业。
8. **费用由用户补充。** 购入杂费可填契税、维修资金等；年持有费用可填物业、维修、保险及后续装修家电更新预算。商品房出售费用使用售价比例近似，不自动计算税法或中介收费。
9. **不存在出租收入或其他资产负债。** 模型只包含用户输入的初始现金、家庭收支、住房和住房贷款；不代表完整家庭资产负债表。
10. **收益为名义、税费后情景值。** 未自动扣投资费用及相关税费，不模拟波动、亏损路径或产品风险。
11. **不擅自设置负回购价的下限。** 若输入使回购公式得到负值，页面提示超出合理适用范围，此时应调整参数并核实真实规则。
12. **输入范围属于软件边界。** 贷款期限和居住年限支持 1–40 年整数，并不代表所有年龄、产品或保障房退出规则允许这些期限。

## 使用与部署

项目不需要后端、数据库、安装依赖或构建步骤。

```text
dist/
├── index.html   # 页面结构、样式与说明
├── app.js       # 参数输入、校验、结果渲染、图表与交互
└── model.js     # 贷款、回购、净成本和净资产模型
```

本地使用：直接打开 `dist/index.html`，或在 `dist` 目录启动静态文件服务：

```bash
python3 -m http.server 8000
```

然后访问 `http://localhost:8000`。

部署到 GitHub Pages：将上述三个文件放在仓库根目录，在仓库 **Settings → Pages** 中选择 **Deploy from a branch → main → /(root)**，保存后使用 Pages 显示的实际网址访问。README 可放在同一仓库根目录。

如果你的 GitHub 仓库已经采用根目录结构，更新时直接替换根目录下的三个网页文件，不必新增 `dist` 文件夹。

## 数据与隐私

当前代码的计算在访问者浏览器中进行，不主动将输入参数发送到后端，不使用数据库或浏览器持久存储保存参数；刷新页面后恢复默认值。

网站托管服务仍可能按照其政策记录访问日志。项目不承诺托管平台层面的匿名性或零数据收集。

支持相应能力的浏览器可通过页面提供的 WebMCP 工具读取计算结果并修改参数。用户应自行决定是否允许其他工具访问页面中的输入及结果。
